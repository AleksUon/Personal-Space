# Personal Space — рабочий прототип MVP

## Запуск на Windows
1. Установите Python 3.11 или новее с python.org, отметив **Add Python to PATH**.
2. Распакуйте архив.
3. Дважды нажмите `start_windows.bat` (первый запуск установит PySide6 через Интернет).

Данные хранятся локально в `%USERPROFILE%\PersonalSpaceData`.

## Реализовано
- Несколько независимых дневников, включая тип «Сновидения».
- Визуальный редактор на всю рабочую область с форматированием.
- Автосохранение через 900 мс и Ctrl+S, даты событий и пробуждения.
- Поиск по тексту и заголовку, две темы, резервное копирование и восстановление.
- Удаление записей и дневников с подтверждением (пока без корзины).

## Не реализовано
**Это прототип, не защищённое хранилище.** База SQLite и ZIP-копии НЕ зашифрованы; нет мастер-пароля, синхронизации, медиа, календаря, тегов, статистики, перетаскивания панелей. Не используйте для конфиденциальных записей.

## Разработка
Запуск из терминала: `python -m pip install -r requirements.txt`, затем `python main.py`.
