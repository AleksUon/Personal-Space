# Personal Space — этап 3: организация дневников и сновидений

Настольное приложение для Windows на Python 3.11+, PySide6 и SQLite в зашифрованном хранилище (AES-256-GCM, ключ из мастер-пароля через scrypt).

## Запуск

1. Установите Python 3.11+ для Windows (с включённым `py` launcher).
2. Распакуйте архив **в новую папку** и запустите `start_windows.bat`.
3. При первом запуске придумайте мастер-пароль (не менее 12 символов).
4. Приложение использует каталог `%USERPROFILE%\PersonalSpaceData`, как и этап 2. **Если у вас уже есть данные второго этапа, перед запуском версии 3 сохраните резервную копию через прежнюю версию.**
5. На первом запуске новой версии выполняется обновление схемы базы. Файл `vault.psv` остаётся зашифрованным. Старые записи сохраняются.

Если запускаете из терминала:

```powershell
py -m pip install -r requirements.txt
py main.py
```

## Возможности этапов 1–2

- Отдельные дневники, дневник сновидений, rich-text редактор, автосохранение, поиск.
- Полнообластной редактор, светлая Ivory и тёмная Midnight темы.
- Мастер-пароль, шифрование локальной базы, автоблокировка, смена пароля.
- Зашифрованное резервное копирование, восстановление, импорт незашифрованной базы первого этапа.

## Новые возможности этапа 3

- **Календарь:** Файл → Календарь. Дни с записями выделены цветом; выбор даты показывает соответствующие записи, двойной щелчок открывает редактор. Дата сна = дата пробуждения; её можно изменить в редакторе.
- **Теги и категории:** Файл → Управление тегами / Управление категориями; в открытой записи кнопки «Теги» и «Категория». Одна категория внутри дневника, много тегов у записи.
- **Корзина:** удалённая запись перемещается в корзину; можно восстановить или окончательно удалить. Окончательное удаление записи удаляет и её вложения.
- **Избранное:** кнопка со звёздочкой в редакторе.
- **Сновидения:** кнопка «Сон» — необязательные поля яркости (1–5), осознанности, эмоций, персонажей, мест, авторской интерпретации. Установка даты пробуждения остаётся в заголовке редактора.
- **Шаблоны:** создание и вставка текста в запись без изменения старых записей.
- **Вложения:** PNG, JPEG, WebP, MP3, WAV, M4A, до 12 МБ на файл. Кнопка «Вложения» открывает прикрепление, экспорт и удаление. Вложения хранятся внутри зашифрованной базы и включаются в защищённую копию. **Воспроизведения внутри программы и миниатюр пока нет**: экспорт сохраняет файл в указанном пользователем месте **без шифрования** после предупреждения.

## Ограничения и защита

- Это исходный код и прототип, не установщик EXE.
- Требуется тестирование на целевой версии Windows. Автоматические тесты хранилища и моделей выполнены; оконный интерфейс на Windows не проверен.
- Не реализованы: синхронизация между ПК, перетаскиваемые панели, статистика и напоминания; полнофункциональный аудиоплеер, просмотр изображений, фильтры поиска по тегам/категориям.
- При блокировке Python не гарантирует стирание секретов из памяти; содержимое открытой базы также доступно в оперативной памяти при разблокированном приложении.
- Не предусмотрено восстановление забытого мастер-пароля. Старые резервные копии могут требовать старый пароль. Сохраните пароль отдельно.
- Старые незашифрованные файлы из MVP **не удаляются автоматически**. Шифрование новых данных не удаляет прежние копии на диске и других носителях.
- Большие вложения увеличивают размер базы и время её перешифрования при каждом сохранении. Не используйте программу для больших медиа-коллекций до внедрения отдельного зашифрованного хранилища вложений.
- Не проводился независимый криптографический аудит; не следует считать прототип средством защиты от всех атак или полностью готовым хранилищем высокочувствительных данных.

## Проверки

```powershell
py -m unittest -v test_security test_organization
```

Проверяются: шифрование, пароль, backup/restore, импорт старой базы, обновление схемы, теги, категории, корзина, календарная дата сна, параметры снов, вложения, шаблоны, избранное и отсутствие фрагментов из тестовых текстов внутри зашифрованного файла.
